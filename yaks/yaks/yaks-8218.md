Found while designing yaks-93ee ([design dok](/doks/design/files-directories-archives.md)). `sources::walk_dir` tests `p.is_dir()` / `p.is_file()`, which follow symlinks. So a symlink inside a directory passed to `yaks attach <id> <dir>` or `yaks source add <dir>` is walked into: a link to `/etc` failed the whole attach with `error: Permission denied (os error 13)`, and a link to a readable directory outside the tree would copy its files into the farm.

The TUI directory view already refuses symlinks (`tui/dirview.rs::list`). The walk should do the same (`e.file_type()`, which does not follow) and report each symlink in the skipped list, so nothing is left out silently.

Evidence wanted: a test with a symlinked file and a symlinked directory inside the walked directory, neither copied, both listed as skipped.

*symwalk-1*

Decision: a symlink (to a file or a directory) is listed as `<rel>` with no trailing `/`. It is not a directory we kept or skipped as one, and `/` would suggest the tree was walked; rejected: `<rel>/` for dir links, `<rel> -> target` (leaks the target path into the `skipped:` field and the note). A link named like a `WALK_SKIP` entry (`node_modules` link) is reported once, as a plain `<rel>`.

Decision: also skip anything that is neither a regular file nor a directory (socket, FIFO, device), reported the same way, instead of dropping it silently as before. Same rule: nothing left out silently.

Decision: `yaks attach <dir>` now reports the skipped list as `source add` does. Both share one new `sources::skipped_summary` (`skipped M: a, b, ... and N more`, five named); attach prints it on its own line after `attached ...`, names prefixed with the stored directory name (`d/etc-link`). Rejected: appending to the `attached` line (it is already parenthesised) and listing all names (can be hundreds). Clap help, docs/cli.md (A directory, source add) and the yaks / yaks-research skills updated.

Evidence: test `walk_dir_never_follows_a_symlink_and_lists_it_as_skipped` (sources.rs) and `a_symlink_in_a_directory_is_skipped_and_reported_not_followed` (tests/attach_dir.rs); the latter fails before the change (verified with src stashed).

Real run, release binary, scratch farm, dir `d/` holding real.txt, `etc-link -> /etc`, `file-link -> real.txt`:

    attached d/ (1 file) to yak-3e39 (yak/yaks/yak-3e39)
    skipped 2: d/etc-link, d/file-link
    exit 0
