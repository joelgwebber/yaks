Eg, if I'm looking at an attachment, I should be able to pin it, so that it shows up in the "starred" list.

This is a little more tricky because it requires that we decide how these should be rendered in the list view, whereas they currently never are.

Doing this sanely will require a careful consideration of internal generalization around doks, files, yaks, sources, et al. When we add archive support (see yaks-93ee), that abstraction will only become more important. Let's take care to ensure the code doesn't turn into spaghetti with a quick and dirty fix.
