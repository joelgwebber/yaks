Eg, if I'm looking at an attachment, I should be able to pin it, so that it shows up in the "starred" list.

This is a little more tricky because it requires that we decide how these should be rendered in the list view, whereas they currently never are.

Doing this sanely will require a careful consideration of internal generalization around doks, files, yaks, sources, et al. When we add archive support (see yaks-93ee), that abstraction will only become more important. Let's take care to ensure the code doesn't turn into spaghetti with a quick and dirty fix. Hopefully it also composes cleanly with the existing detail rendering and navigation stack code.

*herd-files*

Claim (yakherd `herd-files`). Owner: worker `star-1` (Sonnet 5.5), on top of yaks-84fe (`84ffb8b7`). Scope, by the [design dok](/doks/design/files-directories-archives.md#stars-history-and-the-pane-one-name-for-a-subject-yaks-4381):

- A star is a link destination (`links::dest`), canonicalized on load and on toggle (`yaks-1a2b` stays `yaks-1a2b`; a legacy `doks/x.md` reads as `/doks/x.md`). `*` stars the pane's subject whatever it is (text, image, directory, commit view) via `App::doc_link`; a yak or a dok row as today.
- Starred list: yaks and doks keep their rows; any other star is one generic row, `tree::Item::Place` (`RowKey::Place`, `RowKind::Place`): icon by kind, the file's name, where it lives. Enter opens it with `App::open_place`; `*` unstars; `O` takes it out. A star that no longer resolves is skipped.
- Keys: `*` bound in the image, directory and commit contexts as in the viewer (`src/tui/keymap.rs`, `YakStar`), help lines and `docs/tui.md`.
- Out of scope: archives (yaks-93ee, `archive-1` running beside it: it owns `entries.rs`, `locate.rs`, the viewers' constructors and `read_place`/`open_place`; call them, don't edit them), the grammar.
- Evidence: tests (star an attachment, a file in an attached directory, a directory, a code file, a commit; they list in Starred, Enter opens, `*` unstars, a stale one is skipped; a legacy working-set file still works); a headless frame of Starred with mixed rows, attached; the gate; docs.
- Judge: the coordinator at landing.
