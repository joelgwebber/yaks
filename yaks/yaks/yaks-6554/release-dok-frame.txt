│ yaks v0.0.41
│
│ Everything in the farm is now one place to browse: yaks, doks, sources, attachments, directories,
│ archives, commits and files all open in the same pane, link the same way and star the same way.
│ This release also starts yaks' own changelog: every yak records a change line when it is shorn,
│ and releases are computed from the commits that name them.
│
│ • Archives open in place. A .zip or .tar.gz attachment browses like a directory, and a link can
│   point at a line inside one of its files.
│ • One link grammar for lines. path:10, :10-14 and #L10-L14 work on every kind of link; a range
│   opens narrowed to those lines, and w shows the whole file.
│ • Change lines and release notes. yaks shorn --change records what changed for a reader; yaks
│   release changes --check and yaks release dok turn them into this page. The design is the
│   changelog design.
│ • Pinned images from Git LFS. A link pinned to a commit shows the image as it was then, not its
│   LFS pointer.
│
│ Added
│
│ • Archive attachments (.zip, .tar, .tar.gz, .tgz) browse read-only like directories, and links
│   reach files inside them (<id>/code.zip/src/main.rs#L2). (yaks-93ee)
│ • * stars whatever the pane shows: a yak, a dok, a source, an attachment, a directory or a file
│   inside an archive. (yaks-4381)
│ • yaks shorn --change "<line>" records a yak's change line (and --no-change says there is none);
│   the TUI shear prompt offers the title to edit as that line. (yaks-bcb8)
