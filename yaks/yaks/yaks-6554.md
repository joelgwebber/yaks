The TUI renders `<!-- ... -->` as literal text (inline HTML is not rendered). Release doks (yaks-c708) wrap their generated block in `<!-- yaks:changes -->` / `<!-- /yaks:changes -->`, so the markers show in the pane; GitHub hides them. A whole-line or block HTML comment should render as nothing. Evidence: yaks-c708/release-dok-frame.txt. Update the yaks skill's 'Notes and descriptions' line (inline HTML shows as literal text) and src/brief.rs notes line if the rule changes.
