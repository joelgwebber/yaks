It looks like we currently only render inline images in yaks/docs, if they're in their own block/paragraph. So a line like this doesn't render anything but the link:

`Here's an image: ![some image](some-image.png)`

At the very least we should render these on their own line if they're at the end of the block. But also fine to just render them regardless, splitting up the text block. I don't see any obvious reason to get wacky with text wrapping and other complex layout strategies.
