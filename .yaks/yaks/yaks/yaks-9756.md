Keep code checkouts from paying for a farm full of sources and a long history of small commits, and keep a research farm itself cheap to clone.

## Facts

- A plain `git clone` fetches every branch under `refs/heads/`, so every clone of a code repo fetches the whole farm branch: its history and every attachment and source ever committed. Delta clones borrow objects from the host, so they pay once per machine.
- Today this farm's whole repo packs to about 9 MiB. The `joel` repo's `raw/` is 8.8 MiB with 37 sources after a week of use; PDFs and screenshots dominate.
- Per-change commits (commit model yak) multiply the farm's commit count.

## Proposal

1. **Binary originals go through Git LFS on the farm branch.** `yaks init`/`migrate` writes `.gitattributes` on the farm branch routing images, PDFs and archives under `sources/` and attachment dirs to LFS. `source.md` and `extracted.md` stay plain text (capped at 1 MiB, as in Hearth), so search and diffs work without fetching originals. A clone then fetches pointers; the bytes come down on checkout of the farm worktree only.
2. **A research-heavy farm can live in its own repository.** This already works (`yaks init --farm <checkout>`, `git config yaks.farm`): code clones then never see it. The workflow skill says when to choose it (many sources, several herds, or a farm shared across repos).
3. **The farm worktree is a partial clone where the host allows it** (`--filter=blob:none` on the farm fetch), so old blobs arrive only when `yaks commits` or a pinned peek asks for them.
4. **Measure, then decide on more.** A small script reports the farm branch's pack size, commit count, and largest blobs; run it on this farm and on the `joel` farm after migration, before and after a week of per-change commits.

## Rejected for now

- Moving the farm out of `refs/heads/` (to `refs/yaks/*`) so clones skip it by default: it worked in the git-store research (`yaks-4fe6`, dead), but every git tool and host UI stops seeing the farm, and push and fetch need custom refspecs.
- Not committing originals at all: a source has to be reproducible from the farm, or citing it means nothing.
