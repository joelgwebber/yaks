▸ 2026-11-01T23:03:41Z [import-1]

Decision: sessions go to a top-level `sessions/` (not under `sources/` or `wiki/`), mirroring `raw/sessions/` -> `sessions/` as the claim says. doctor reads a top-level dir as a herd only when it holds `yaks/` (`store::herd_dirs`), so `sessions/` is not a herd; `sessions` is not in `RESERVED_HERD_NAMES` though, so `create --herd sessions` is still allowed (store.rs is out of scope: follow-up).

Decision: the commit is made by the module, not by the per-change autocommit: autocommit generates the subject from changed paths ("yaks: update <300 paths>") and cannot name the source repo and HEAD. The module takes `store::lock_uncommitted`, writes, then `git add` + `git commit --only` on exactly the paths it wrote (pathspecs from stdin, literal), so unrelated dirty farm files are never swept in. `autocommit::identity_env` becomes `pub(crate)` (one word) so a machine with no git identity still commits.

Decision: relative links without `..` (siblings, below) are left as written when the target exists in the source repo (a page and its siblings move together), and counted as dangling when it does not. Only `..` links are rewritten: to `/wiki|schemas|sources|sessions/...` if the target is in an imported area (dangling ones too, and reported), to `code:<path>` if it exists elsewhere in the repo, left unchanged and reported if it exists nowhere.
