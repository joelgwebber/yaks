▸ 2026-11-03T04:28:36Z [herd-tui]

Claim (yakherd herd-tui): worker `pane-1` (Sonnet 5.5), from main after phase 3b lands. Runs in parallel with phase 6a (`query-1`); the scopes are disjoint by symbol.

**Task.** The right pane holds a subject, and the text and image viewers stop being modal overlays ([design §2](/wiki/design/tui-model.md#2-the-pane-and-its-subjects), decision 5).

**State.** `App.doc: Option<DocPane>` where `enum DocPane { Text(AttachView), Image(ImageView) }`. `Overlay::Attachment` and `Overlay::Image` go; every site that set or matched them uses `App.doc`. `viewer_back`/`viewer_fwd` stay as they are (phase 5 merges stacks). The pane's subject is:

- `doc` when `Some`;
- else the selected row's (yak detail, shed detail).

**Focus.** Opening a doc sets `Focus::Detail`. `Ctx::Viewer` and `Ctx::Image` remain contexts in the keymap (phase 4b/5 fold them), chosen by `surface_ctx` when `doc` is `Some`.

**Keys.** Global keys now work with a page open, because the doc is no longer an overlay:

- `Tab`/`[`/`]` keep their viewer meaning (next link) while it has focus;
- `U`, `W`, `?` and `#` add bindings in `Ctx::Viewer` and `Ctx::Image` running the same commands as the list;
- `v` (view picker) does NOT, since `v` is visual select in the viewer.

**Closing.** `Esc`/`h`/`q` close the doc as today (phase 7 changes `q`). Closing returns focus to wherever it came from: the list, or the yak detail it was opened from. Record that in `DocPane`.

**Switching.** Switching view (`Tab` from the list, a tab click) or `J`/`K` closes the doc.

**Render.** The right pane draws the doc when `Some` (today's `render_attachment`/`render_image`); the list stays drawn on the left, focused-looking only when focus is List. Remove the "draw the list unfocused while any overlay is up" special case for document rows that phase 3a kept to hold the Wiki SVGs (record which snapshots change).

**Mouse.** A click in the list while a doc is open selects the row and closes the doc.

**Out of scope.**

- The `/` query and All view (phase 6a is changing `open_search`, `Overlay::Search`, `build_rows`, `view_count`, the tab-row chip).
- The detail pane's `detail_*` fields (phase 4b).
- Merging back stacks (phase 5).
- Any key change other than adding `U`/`W`/`?`/`#` to the viewers.

Anything else: `yaks ask yaks-0906`.

**Evidence.**

- Gate: `env -u YAKS_DIR -u YAKS_ACTOR cargo test --workspace`, fresh `TMPDIR`.
- New tests:
  - with a page open, `U` requests a sync and the page stays open;
  - `?` opens help over it, and closing help returns to it;
  - `Esc` from a page opened from a yak detail returns to that detail;
  - `Tab` in the viewer still moves to the next link;
  - a list click closes the doc.
- Snapshots: the viewer, image and Wiki frames may change only where the list's focus styling changes. Name each in a `Decision:` note.
- Regenerate docshots (`cargo test -p yaks docshots -- --ignored`).
- Docs: `docs/tui.md` (the viewer is part of the pane, global keys work in it), `AGENTS.md` (the `Overlay` description in Layout).
- Attach a headless frame of a page open with the help overlay over it.
