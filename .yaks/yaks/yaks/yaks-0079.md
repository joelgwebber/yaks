Done on branch `scheduling`.

- `--due` on `create`/`update` takes `+Nd` / `+Nw` from today (stored as a date); anything else that is not a date or datetime is refused naming the accepted forms. The parser is `When::parse_input` and `resolve_due` in `src/recur.rs`, the one door the TUI snooze key will use.
- `yaks snooze <id>... [--to <when>]` (default `+1d`) moves `due:` and appends a `kind: snooze` note (`snoozed until X (was due Y)`); a shorn or dead yak is refused with the regrow hint; every id is tried and the exit is non-zero if any failed. `Farm::snooze` takes the lock once.
- Evidence: three new `tests/recur.rs` tests (failed first), a unit test for the parser, `cargo test` full gate green; run by hand on a scratch farm: `create --due +2d`, `snooze --to +1w` left the snooze note, snoozing a shorn yak and `--due=-2d` exit 1 with the message.
- Docs and help: `docs/cli.md` (command table, due paragraph, note-kind table), README, the `yaks` skill's due paragraph, and the clap help for `--due` and `snooze`.

Decision: `+Nm`/months are refused (a month has no fixed length; use a date). `+Nd` counts from the local calendar day, not UTC.
