Follow-up to yaks-be20. Seventeen yaks in the surveyor farm (`survey-0419`, `survey-1616`, `survey-1633`, ...) carry an evidence markdown plus its PNGs, each PNG linked in the yak's body as `![..](<id>/<file>)`. With yaks-be20 the document's own bare links resolve, so the body links are redundant: the yak could link only the `*-evidence.md`.

A human's call (it edits another repo's farm, and some notes cite an image by link). Options: leave as is; or a one-off script that removes each `![..]` line whose file the yak's evidence document already embeds, keeping the files.
