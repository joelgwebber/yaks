Which key replaces `L` for tags? In both the yak list and the yak pane the only free Shift keys are `I` and `Y` (`T` is already Type and `P` Priority; checked in `src/tui/keymap.rs`).

1. **`I` for tags, everything else unchanged.** Smallest change, but `I` has no mnemonic.
2. **Swap: tags on `T`, type moves to `Y`.** Tags are edited far more often than type, and `T` is the mnemonic. Costs a muscle-memory change for type.
3. **Keep `L`.** Rename only the help text and docs ("Tags (L)") and close the yak.

Lean: 2. A user's `keys:` overrides are keyed by command name (`yak.tags`, `yak.type`), so they survive the move either way. Landing this before yaks-c3d0 avoids a conflict in `keymap.rs` and `docs/tui.md`.
