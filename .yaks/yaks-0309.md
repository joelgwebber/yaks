I think it would be useful to prioritize the ordering of the sheds list a bit:
- Main/current on top (which I think is already true?)
- Priority: active > stale > idle
- Within each state, order by number of yak changes, descending.

Open to tweaks of that, but that feels like an ordering that would tend toward something like _main -> coordinator -> workers_ in broad terms at least.
