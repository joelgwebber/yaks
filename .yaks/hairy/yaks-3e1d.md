While the TUI is preferable most of the time, it would on occasion be really helpful to be able to display images, rendered markdown, PDFs, etc in a web UI. For starters, I'm thinking something really simple that just lets you quickly open a browser pointing at a local server for these things (eg, so we can render markdown, not just serve raw files).

Then we might consider adding some other basic navigation facilities. Eg, navigating across markdown links, etc. Just for simple local use.
