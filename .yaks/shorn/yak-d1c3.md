We get scroll-wheel support by default in most terminals, mapping to up/down, but it would be nice
if you could use it more traditionally:
- click on things to select them,
- scroll the *viewport* with the wheel,
- back/forward buttons.

All to the extent possible of course, depending upon how mouse actions map to terminal inputs. I
think this presupposes the existence of a "viewport scroll" option for the various views, which we
should also map to the traditional vim bindings (ctrl-Y/E).
