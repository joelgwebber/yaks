Found in trial round 1 (yaks-6a34): `yaks preflight --push-main` from the coordinator's clone failed with "there is no `local` remote", though the clone has one. `preflight::local_checkout` asks `git rev-parse --show-toplevel` of the FARM root; under `live_branch:` that is the farm worktree (`~/src/yaks-farm`), not the checkout that will run `git push local main`. Fix: the local-remote check runs in the checkout the command was invoked from (the cwd), which is the one pushing; the git-state check of the farm keeps using the farm root. Evidence: a test with the farm in a separate worktree and `local` only on the invoking checkout: fails before, passes after.
