# yaks v0.0.11

_Backfilled on 2026-11-22 (yaks-3696)._ The UI lightning round: scrolling that moves only as far as needed, a `#` go-to-yak picker, mouse support, bracketed paste, renaming attachments, `slaughter --family`, and label normalization. Plain `slaughter` now refuses a parent with live descendants. From its release yak, [yaks-137a](/yaks/yaks/yaks-137a.md).
